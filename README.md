# NetSpeedWidget

## Summary

NetSpeedWidget is a simple WPF application that displays network speed information. The application provides various features such as changing text color, locking position, and handling startup events.

## Features

- **Text Color Options**: Users can change the text color to White, Green, Yellow, Cyan, or Red.
- **Lock Position**: Users can lock the window's position on the screen.
- **Startup Handling**: The application handles startup events appropriately.
- **Exit Option**: Users can exit the application from the menu.
